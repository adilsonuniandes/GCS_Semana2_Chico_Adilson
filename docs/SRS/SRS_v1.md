# Especificación de Requisitos de Software – SmartFin Móvil

## Requisitos funcionales

- RF-001: El sistema deberá permitir registrar la información del balance de comprobación de una empresa.
- RF-002: El sistema deberá procesar automáticamente la información contable registrada.
- RF-003: El sistema deberá calcular indicadores y razones financieras.
- RF-004: El sistema deberá mostrar el estado de situación financiera de la empresa.
- RF-005: El sistema deberá presentar KPIs para analizar la evolución financiera.
- RF-006: El sistema deberá generar reportes de apoyo para la toma de decisiones.

## Requisitos no funcionales

- RNF-001: El sistema deberá presentar una interfaz clara y comprensible para usuarios sin conocimientos avanzados de contabilidad.
- RNF-002: El sistema deberá proteger la información financiera almacenada.
